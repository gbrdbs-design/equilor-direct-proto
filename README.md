# Equilor Direct – prototípus

Kattintható HTML prototípus az Equilor Direct regisztrációs folyamatához és ügyfélfelületéhez.

## Tartalom

- Bejelentkezés
- Regisztráció (1–2. lépés, hibaállapotok, beküldve képernyő)
- Visszaigazoló e-mail
- Ügyfél oldal: nyitóoldal, számlák, postafiók, megbízások, hozzáférések
- Desktop és mobil (430 px) nézet

## Használat

Nyisd meg az `index.html` fájlt böngészőben. A bal alsó sarokban lévő prototípus-navigátorral lehet a képernyők között váltani.

Egyetlen önálló fájl, build lépés nincs. Külső függőség csak a Poppins betűtípus (Google Fonts).
